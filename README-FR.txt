BÉTON TG PREFA V3 — BASE DE DÉPART

Modules inclus : Calcul des matières premières, Stock, Production, Camions, Rapports, Formules & Densités, Paramètres.
Les modules Commandes, Clients et Dépenses ne sont pas inclus.

Formules d'origine par 1 m³ :
B30 : G1 543 kg, G2 534 kg, SL 427 kg, SC 427 kg, Ciment 320 kg, Adjuvant 3,4 kg, Eau 158 kg.
B35 : G1 543 kg, G2 530 kg, SL 418 kg, SC 417 kg, Ciment 350 kg, Adjuvant 3,8 kg, Eau 156 kg.
Densités : G1 1450 kg/m³, G2 1450 kg/m³, SL 1600 kg/m³, SC 1450 kg/m³.

Centres de démonstration : CAB AGADIR, CAB MARRAKECH, CAB BENGUERIR, CAB FES. PIN initial de démonstration : 1234 pour chacun. Changez les PIN lors des essais. Ce mécanisme local n'est PAS une sécurité de production.

IMPORTANT : cette version utilise localStorage. Les données ne sont pas partagées entre appareils à ce stade. Le schéma Supabase fourni est préparatoire ; l'authentification, les politiques RLS et la synchronisation doivent être intégrées et testées avant l'utilisation réelle en ligne. Ne saisissez pas de données sensibles dans cette version de démonstration.

Déploiement : extraire le ZIP, téléverser le contenu du dossier à la racine d'un nouveau dépôt GitHub (ex. beton-tg-prefa-v3), commit sur main, puis Settings > Pages > Deploy from a branch > main > /(root).
